# Code for pulsatile smart-fluid flows

This repository contains the FEniCS/DOLFIN code accompanying the article
"Pulsatile Flows for Simplified Smart Fluids with Variable Exponent Power-Law:
Analysis and Numerics".

The package is prepared for publication via GitHub and archival via Zenodo. It
contains the experiment code, plotting scripts, and regenerated paper figures.
Numerical output directories are generated by the runners and are not part of
the archived source tree.

## Contents

```text
.
├── pLaplaceMixed/          # Sections 7.1 and 7.2: reduced 1D mixed problems
├── pNavierStokesMixed/     # Section 7.3: direct 2D comparison experiment
├── run_all_sections.py     # Convenience runner for Sections 7.1--7.3
├── environment.yml         # Conda environment specification
├── requirements.txt        # Python package notes
├── LICENSE                 # BSD-3-Clause license
├── CITATION.cff            # Citation metadata
├── .zenodo.json            # Zenodo metadata
├── MANIFEST.md             # Included and excluded files
└── CODE_AVAILABILITY.md    # Article text template
```

## Software Requirements

The experiments require a Python environment with FEniCS/DOLFIN.  The code was
prepared for the setup described in the article:

- FEniCS/DOLFIN 2019.1.0
- MUMPS linear solver support
- Python with `numpy`, `scipy`, `sympy`, and `matplotlib`
- A LaTeX installation for publication-style plot labels

One way to create a suitable Conda environment is

```bash
conda env create -f environment.yml
conda activate pulsatile-smart-fluids
```

Depending on the platform, installing FEniCS/DOLFIN 2019.1.0 via Docker or a
system package manager may be more reliable than a fresh Conda solve.

## Quick Smoke Test

From the repository root:

```bash
python3 run_all_sections.py --section all --quick --no-plots
```

This checks the workflow with reduced refinement levels.  It is not intended to
reproduce the paper figures quantitatively.

## Reproduce the Paper Runs

Run all experiments without opening plot windows:

```bash
python3 run_all_sections.py --section all --no-plots
```

Run individual sections:

```bash
python3 run_all_sections.py --section 71 --no-plots
python3 run_all_sections.py --section 72 --no-plots
python3 run_all_sections.py --section 73 --no-plots
```

The default refinement parameters are

| Section | Script | Default | Loop |
| --- | --- | --- | --- |
| 7.1 | `pLaplaceMixed/run_section_71.py` | `--nmax 12` | `n=1,...,11` |
| 7.2 | `pLaplaceMixed/run_section_72.py` | `--nmax 10` | `n=1,...,9` |
| 7.3 | `pNavierStokesMixed/run_section_73.py` | `--nmax 9` | `n=1,...,8` |

Section 7.3 is substantially more expensive than Sections 7.1 and 7.2 because
it solves the full 2D Taylor-Hood approximation and writes large snapshot
directories.

## Figures

The regenerated Figures 5, 6, 7, 8 and 9 are included in
`pLaplaceMixed/plots/`. Regenerated Section 7.3 plots are included in
`pNavierStokesMixed/plots/`.

To recompute the Section 7.1--7.2 data and regenerate the figures:

```bash
python3 run_all_sections.py --section 71 --no-plots
python3 run_all_sections.py --section 72 --no-plots
```

```bash
cd pLaplaceMixed
python3 paper_figures.py --figure all --save-dir plots --format pdf png --no-show
```

If LaTeX text rendering is unavailable:

```bash
python3 paper_figures.py --figure all --save-dir plots --format pdf png --no-show --no-tex
```

Section 7.3 plots are generated after the Section 7.3 computation:

```bash
cd pNavierStokesMixed
python3 run_section_73.py --stage plot
python3 run_section_73.py --stage surface
```

To save the Section 7.3 figures directly:

```bash
python3 ErrorPlot.py --save-dir plots --format pdf png --no-show
python3 PlotSolution.py --save-dir plots --format pdf png --no-show
```

## Output Policy

The repository excludes transient files, Python caches, and generated numerical
output directories. These files are reproduced by the runner scripts. In
particular, the following output directories are not part of the archived source
tree:

- `pLaplaceMixed/Womersley1/`
- `pLaplaceMixed/Womersley5/`
- `pLaplaceMixed/Womersley10/`
- `pLaplaceMixed/Const15/`
- `pLaplaceMixed/Const25/`
- `pLaplaceMixed/Sym1/`
- `pLaplaceMixed/NonSym2/`
- `pNavierStokesMixed/Comparison/`
- `pNavierStokesMixed/Comparison1D/`
