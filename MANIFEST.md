# Manifest

## Included

- `run_all_sections.py`: convenience runner for Sections 7.1--7.3.
- `pLaplaceMixed/`: reduced 1D mixed formulation for Sections 7.1 and 7.2.
- `pLaplaceMixed/plots/Figure5.*`, `Figure6.*`, `Figure7.*`, `Figure8.*`,
  `Figure9.*`:
  regenerated paper figures.
- `pNavierStokesMixed/`: Section 7.3 2D comparison code.
- `pNavierStokesMixed/plots/Figure11.*`: regenerated Section 7.3
  convergence and approximation plot.
- `pNavierStokesMixed/plots/Figure12_pressure.*` and
  `pNavierStokesMixed/plots/Figure12_velocity.*`: regenerated Section 7.3
  pressure and velocity surface plots.
- `LICENSE`: BSD-3-Clause license.
- `CITATION.cff` and `.zenodo.json`: citation and deposition metadata.
- Documentation and environment metadata.

## Excluded

- Python caches (`__pycache__/`, `*.pyc`).
- macOS metadata (`.DS_Store`).
- Matplotlib caches.
- Generated Section 7.1 and Section 7.2 data directories:
  `pLaplaceMixed/Womersley1/`, `pLaplaceMixed/Womersley5/`,
  `pLaplaceMixed/Womersley10/`, `pLaplaceMixed/Const15/`,
  `pLaplaceMixed/Const25/`, `pLaplaceMixed/Sym1/`,
  `pLaplaceMixed/NonSym2/`.
- Generated Section 7.3 snapshot directories:
  `pNavierStokesMixed/Comparison/` and `pNavierStokesMixed/Comparison1D/`.
- Generated Section 7.3 result pickles.

The excluded outputs are regenerated by

```bash
python3 run_all_sections.py --section all --no-plots
```
